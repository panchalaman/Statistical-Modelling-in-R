# Statistical Modelling in R

Coursework and projects for statistical modelling using R programming language.

## Topics Covered

- Linear Regression & Multiple Regression
- Logistic Regression
- ANOVA & MANOVA
- Time Series Analysis
- Hypothesis Testing
- Model Diagnostics & Validation
- Bayesian Statistics

## Tech Stack

- R
- RStudio
- ggplot2, dplyr, tidyr
- caret, lme4, forecast

## Project Structure

```
├── scripts/         # R scripts for analysis
├── data/            # Datasets
├── reports/         # RMarkdown reports
└── figures/         # Generated plots and visualizations
```

## Getting Started

1. Install [R](https://cran.r-project.org/) and [RStudio](https://rstudio.com/)
2. Clone this repository
3. Open the `.Rproj` file in RStudio
4. Install required packages:

```r
install.packages(c("ggplot2", "dplyr", "tidyr", "caret", "lme4"))
```
